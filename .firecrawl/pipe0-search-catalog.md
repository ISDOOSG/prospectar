# Search Catalog

[Request a search](https://github.com/pipe-0/pipe0/discussions/new?category=ideas)

Searches give you access to datasets for finding leads and companies using various filters. You can combine multiple searches into one request and deduplicate the results.

Looking for the old search docs?

The legacy search endpoint documentation is still available at [legacydocs.pipe0.com](https://legacydocs.pipe0.com/).
